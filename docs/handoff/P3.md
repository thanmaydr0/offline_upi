## MANUAL STEPS FOR YOU

1. Install the dev-client APK provided by P0 on an Android phone.
2. From the repository root in PowerShell, run:

   ```powershell
   cd mobile
   $env:EXPO_PUBLIC_USE_MOCKS = "1"
   npx expo start --dev-client
   ```

3. Connect the phone and computer to the same network, open OfflinePay on the phone, and use the dev-client QR code to connect.
4. Click through onboarding, Home, Activity, Settings, Get offline-ready, Pay, Receive, Received offline, and Security status. Report any layout or interaction that looks off.
