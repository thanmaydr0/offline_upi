## MANUAL STEPS FOR YOU

1. Install the latest preview APK on both phones and allow camera access. The
   **Scan QR** button starts the in-app camera scanner. It reads QR codes with
   the bundled ML Kit barcode model included in the APK; it does not open the
   Google Code Scanner UI or need Google Play services, internet, or a first-use
   model download. Tap **Scan another QR** to retry the same code.
2. Complete setup and sync on both phones and load vouchers on the payer. Then
   put both phones in airplane mode. The receiver creates an OfflinePay request
   QR; the payer scans it, approves the payment, and displays proof QR frame(s)
   for the receiver to scan. Wait for **Payment received**. The payer's
   spendable offline balance decreases locally, and the receiver saves the
   incoming amount locally as pending settlement. Reconnect later to settle
   with the backend.
3. Only OfflinePay request/proof QR codes are accepted by this offline flow. A
   regular bank UPI QR is not an OfflinePay transfer QR.

   Physical-device validation remains unperformed from this workspace: `adb
   devices -l` returned an empty device list, so camera focus, brightness/glare,
   scan speed, and the two-phone airplane-mode flow could not be observed here.
   No hardware guarantee is claimed. Check device availability from the project
   root with:

   ```powershell
   adb devices -l
   ```
