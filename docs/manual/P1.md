# P1 manual steps

1. Generate three throwaway wallets from the repository root with this one-line command. It prints their private keys once to the terminal; store them locally and never commit them:

   ```powershell
   node --input-type=module -e "import { generatePrivateKey, privateKeyToAccount } from 'viem/accounts'; for (const role of ['deployer', 'issuer', 'relayer']) { const privateKey = generatePrivateKey(); console.log(JSON.stringify({ role, address: privateKeyToAccount(privateKey).address, privateKey })); }"
   ```

2. Fund the deployer and relayer wallets with Base Sepolia ETH from a public faucet. The issuer wallet only signs typed data and does not need ETH.
3. Create `contracts/.env` from the example and fill in the throwaway deployer key, Base Sepolia RPC URL, relayer address, and issuer address:

   ```powershell
   Copy-Item contracts/.env.example contracts/.env
   ```

   Set `DEPLOYER_PRIVATE_KEY`, `RPC_URL_BASE_SEPOLIA=https://sepolia.base.org`, `RELAYER_ADDRESS`, and `ISSUER_ADDRESS` in that file. Keep `.env` private.
4. Deploy the test token and vault:

   ```powershell
   npm run deploy:baseSepolia -w contracts
   ```

5. Review `contracts/deployments/baseSepolia.json`. It contains only deployment addresses and public chain/block metadata. Commit it after the deployment:

   ```powershell
   git add -f contracts/deployments/baseSepolia.json
   git commit -m "P1: record Base Sepolia vault addresses" -- contracts/deployments/baseSepolia.json
   ```

6. Tell the next sessions the value of `addresses.OfflineVault` in that JSON so they can configure the backend and mobile app.

Never reuse wallets that hold real funds.

The Hardhat tests print gas use to the console. The latest local run reported 115,550 gas for one successful redemption and 164,227 gas for a successful two-item batch; exact totals can vary with signature calldata.
