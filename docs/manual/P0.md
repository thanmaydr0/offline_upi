# P0 manual setup

1. Create a free Expo account at [expo.dev](https://expo.dev).
2. Install the EAS CLI:

   ```sh
   npm i -g eas-cli
   ```

3. Sign in to the Expo account you want to use:

   ```sh
   eas login
   ```

4. Link this app to your Expo account:

   ```sh
   cd mobile && eas init
   ```

5. Start the Android development build now. The free queue can take 30 to 90+ minutes; start it and continue with the next prompts while it builds:

   ```sh
   eas build --platform android --profile development
   ```

6. When the build finishes, download the APK to the Android phone and install it. Allow installation from unknown sources if Android asks.
7. Later, connect the phone and laptop to the same Wi-Fi and start Metro:

   ```sh
   cd mobile && npx expo start --dev-client
   ```
