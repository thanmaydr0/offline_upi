# OfflinePay

Hackathon monorepo for OfflinePay. See [the source of truth specification](docs/SPEC.md) and [working rules](docs/RULES.md).

Install workspace dependencies with `npm install`. Run `npm test` and `npm run typecheck` from the repository root. The Android Expo app lives in `mobile/` and can be started with `cd mobile && npx expo start --dev-client` after creating a development build.
